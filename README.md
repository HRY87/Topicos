# Tópicos

Bienvenido al repositorio **Tópicos**. Este proyecto está organizado en diferentes ramas, cada una dedicada a un propósito específico. A continuación encontrarás una descripción detallada de cada rama.

## 📚 Descripción de las Ramas

### 🔗 main
La rama principal del repositorio. Esta es la rama de referencia donde se encuentra la documentación general del proyecto y el índice de contenidos. Desde aquí puedes acceder a información sobre todas las otras ramas.

### 📖 Clases
Esta rama contiene todo el material relacionado con las **clases** y lecciones teóricas:
- Apuntes de clase
- Presentaciones
- Materiales educativos
- Conceptos fundamentales
- Ejemplos básicos

### 🎯 GuiaEjercicios
En esta rama encontrarás **guías de ejercicios** y problemas prácticos para reforzar lo aprendido:
- Ejercicios propuestos
- Problemas resueltos
- Soluciones paso a paso
- Casos de estudio
- Prácticas complementarias

### ✏️ Parciales
Esta rama está dedicada a los **exámenes parciales** y evaluaciones:
- Preguntas de parciales anteriores
- Ejercicios de examen
- Soluciones a pruebas
- Guías de estudio para exámenes
- Material de repaso

## 🚀 Cómo Usar Este Repositorio

1. **Para estudiar los temas**: Ve a la rama `Clases`
2. **Para practicar ejercicios**: Ve a la rama `GuiaEjercicios`
3. **Para modelos de examnes**: Ve a la rama `ModelosDeParciales`
4. **Para ver parciales resueltos**: Ve a la rama `ParcialesResuletos`

## 📝 Navegación

Puedes cambiar entre ramas usando el selector de ramas en GitHub o con git:

```bash
git checkout <nombre-rama>
```
